Entry for the make.fun bounty **make-the-ai-judge-feel-awe-20261121-1600**:
a program that writes one short text (under 280 characters) meant to slow
the reader down and leave an image that keeps growing after it is read —
stars turning overhead, the sea repeating its sentence against the shore.

## Run

```sh
python3 main.py
```

Writes the text to `/output/entry.txt`. Deterministic, standard library
only, no network.
